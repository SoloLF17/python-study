# Estudos de Python

Repositório com exercícios e exemplos desenvolvidos durante meus estudos de Python pelo Curso em Vídeo. Os programas são independentes e praticam, de forma progressiva, lógica de programação e recursos da linguagem.

## Organização

| Pasta | Conteúdo |
| --- | --- |
| [`mundo 1/`](mundo%201/) | Primeiros passos, entrada e saída, operadores, manipulação de texto, condições e exercícios de lógica. |
| [`Mundo 2/`](Mundo%202/) | Estruturas condicionais e de repetição, com desafios numerados de 36 a 71. |
| [`mundo 3/`](mundo%203/) | Tuplas, listas, matrizes, dicionários e funções, com desafios numerados de 72 a 100. |

As pastas também contêm arquivos com exemplos das aulas. No Mundo 3, os exercícios seguem o padrão `aula-exercício`: por exemplo, `a19-e93.py` é o exercício 93 da aula 19.

## Como executar

É necessário ter Python 3 instalado. Na raiz do repositório, execute um arquivo pelo terminal:

```bash
python "Mundo 2/a12-e45.py"
python "mundo 3/a20-e100.py"
```

No Windows, você também pode usar `py` no lugar de `python`. Os exercícios interativos recebem os dados pelo terminal. A maioria usa apenas a biblioteca padrão; `mundo 1/a29.py` também requer o pacote `colorama`:

```bash
python -m pip install colorama
```
