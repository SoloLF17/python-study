# Estudos de Python

Repositório de exercícios e anotações feitos durante meus estudos de Python com o Curso em Vídeo. Cada arquivo é um pequeno programa independente, criado para praticar lógica e os recursos apresentados nas aulas.

## Conteúdo

| Pasta | Conteúdos principais |
| --- | --- |
| [`mundo 1/`](mundo%201/) | Fundamentos, entrada e saída, operadores, strings e condições |
| [`Mundo 2/`](Mundo%202/) | Condições, estruturas de repetição e desafios 36 a 71 |
| [`mundo 3/`](mundo%203/) | Tuplas, listas, matrizes, dicionários e funções; desafios 72 a 100 |

No Mundo 3, os nomes seguem o padrão `aula-exercício`. Por exemplo, `a19-e93.py` corresponde ao exercício 93 da aula 19. Também há arquivos por aula usados para acompanhar os exemplos (`a16.py`, `a17.py` etc.).

## Executar um exercício

É necessário ter Python 3 instalado. No terminal, a partir da raiz do repositório, execute o arquivo desejado:

```bash
python "Mundo 2/a12-e45.py"
python "mundo 3/a20-e100.py"
```

No Windows, também é possível usar `py` no lugar de `python`. Os exercícios interativos recebem os dados pelo terminal. A maioria usa apenas a biblioteca padrão do Python; o arquivo `mundo 1/a29.py` requer a biblioteca `colorama`:

```bash
python -m pip install colorama
```
